# MVEC Viewer

`mvec-viewer.html`をChrome、Edge、Safariなどで開き、`MVECファイル`からMAMEの
`-vector_record`で記録したファイルを選択します。ファイルはブラウザ内だけで処理され、
外部へ送信されません。

ツールのUIは英語のみです。英語版の説明は [README.md](README.md) にあります。

## フレーム指定

- `Data X / N`は、MVEC内で先頭から数えた1始まりのフレーム位置です。
- `Data frame`欄へ番号を入力すると、その位置へ直接移動します。
- `Recorded frame ID`はMVECに格納された0始まりのIDです。
- 共同で確認するときは「データの125フレーム目」のように、`Data X / N`のXを指定してください。

## 画面の並び

フレーム操作(トランスポート・`Data frame`・フレーム位置スライダー)は
ファイル情報行の直下にあります。表示画面はその下です。

## 操作

- `Prev` / `Next`: 1フレーム移動
- `|<` / `>|`: 先頭 / 末尾へ移動
- `Play`: 60フレーム/秒で連続表示
- 左右矢印キー: 前後のフレームへ移動
- Spaceキー: 再生 / 停止
- フレーム位置スライダー: 任意位置へ移動
- `Orientation`: 記録座標を90度単位で回転
- 拡大: マウスホイール(カーソル位置を中心に拡大)/ `＋` `−` ボタン / `+` `-` キー
- 拡大位置の移動: 拡大中にキャンバスをドラッグ。参照モードでも同じように使えます
- 全体表示に戻す: `Fit`ボタン / キャンバスをダブルクリック / `0`キー
- `Show blank moves`: intensity 0のビーム移動経路も表示
- ベクターをクリック: RGB、強度、beam energy、描画時間などを表示
- `Reference mode`(参照モード): 実画面と参照表を横に並べ、選択行までのベクターだけを描画して
  選択行を黄色で強調
- 参照表の行クリック / `Prev row`・`Next row` / `Vector row` / スライダー:
  フレーム内のベクター行を選択
- 参照モード中の上下矢印キー: 前後のベクター行へ移動

読み込み時には全フレームのCRC32を検証します。staleフレームは、MAMEでの再生と同様に
直前の有効なベクターリストを表示します。

## 参照モードの表

`Rows shown`で表示行数を選びます(10 / 15(既定) / 25 / 50 / 100 / 250 / 1000)。表示窓は
選択行を中心に取られ、表の上の行に画面内の範囲が出ます。DOMへ入れるのはこの窓の分だけなので、
2万ベクターのフレームでも操作が重くなりません。窓の外は行操作かスライダーで辿ります。

表は縦横どちらもスクロールします。横は各列を潰さず自然な幅に保つため、縦は選んだ行数が
ウィンドウ高の70%を超えたときです。スクロール中もヘッダー行は固定されます。

記録された値のほかに、次の4列をレコードから算出しています。

| 列 | 意味 |
| --- | --- |
| `len` | 線分長(スクリーン単位)。`hypot(x1-x0, y1-y0) / 65536`。座標は両軸とも1/65536スクリーン単位で格納されているので、フレームの`vis`範囲とそのまま比較できます。 |
| `dt µs` | そのベクターの描画時間 `t1 - t0`(マイクロ秒)。 |
| `dt %` | フレーム全体の描画時間に対する、そのベクターの割合。 |
| `µs/len` | 線分長あたりの描画時間 `dt / len`。実質ビーム速度の逆数なので、通常の線描画ではほぼ一定になり、外れる箇所が目立ちます。 |

表の上の行には、フレーム全体の描画時間(全ベクターの`dt µs`の合計)も出ます。blank移動も
ビームが時間を使うので合計に含めています。

`t0`/`t1`は記録側が時刻を持っているフレームでのみ意味を持ちます。時刻のないフレームでは
上の4列のうち`len`以外が`—`になります。

## 対応フォーマット

MVEC **1.0 / 1.1** を読み込めます(`vector.cpp` の `MVEC_VERSION_MAJOR/MINOR`)。
1.1 はヘッダの system / device 文字列の後に **記録フレーム周期(attoseconds, i64)** が
追加されているだけで、フレームチャンクとベクターレコード(66バイト)は 1.0 と同一です。
周期が記録されている場合はステータス行に `1.1 ... 60.000Hz` のように記録レートを表示します
(1.0 は周期を持たないため非表示)。マイナーが 2 以上のファイルは明示的に拒否します。

このビューアはプリミティブなベクターデータを加算合成で確認するためのものです。
BGFXチェインの残光、Glow、シャドウマスク、HDR/EDRなどは再現しません。
